# My To-Do List

A simple, beginner-friendly To-Do List website built with plain HTML, CSS and JavaScript.  
This project is designed for practising **GitHub Issues**, **branches**, **commits** and **Pull Requests**.

---

## Features

- Add tasks by typing in the text box and clicking **Add Task** (or pressing **Enter**)
- Mark tasks as completed using the checkbox (applies a strikethrough)
- Empty tasks are rejected with a friendly error message
- Clean, responsive layout that works on desktop and mobile

## How to run

No build tools or server needed — just open the file in your browser:

1. Find `index.html` in your file explorer (or Finder on Mac).
2. Double-click it — it will open in your default web browser.
3. Start adding tasks!
